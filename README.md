# Проект: Трекер привычек

## Описание: создание приложения, отслеживающее привычки 

## Установка:
- Клонируйте репозиторий
```git clone https://github.com/McSim555/Habits_tracker``
- Откройте проект habits_tracker в PyCharm версии <= 3.12

## Использование:

1. Откройте ветку feature
``` git branch feature ```

2. Запустите локальный сервер проекта ```habits_tracker``` http://127.0.0.1:8000/

3. Создана модель User для управления пользователями, регистрацией и авторизацией

4. Создана модель привычки Habit с полями:
   owner — создатель привычки
   place — место, в котором необходимо выполнять привычку
   date - дата, когда необходимо выполнять привычку
   time — время, когда необходимо выполнять привычку
   action — действие, которое представляет собой привычка
   is_pleasant — признак приятной привычки
   connected_habit — привычка, которая связана с другой привычкой
   periodicity — периодичность выполнения привычки для напоминания в днях
   prize — чем пользователь должен себя вознаградить после выполнения
   time_to_complete — время, которое предположительно потратит пользователь на выполнение привычки
   is_public — привычки можно публиковать в общий доступ, чтобы другие пользователи могли брать в пример чужие привычки
   created_at - время создания привычки
   updated_at - время обновления
   last_reminder - время отправки последнего напоминания 

5. Подключены валидаторы, пагинация, реализованы права доступа только к своим привычкам или публичным для авторизованных пользователей

6. Описание эндпоинтов можно посмотреть здесь: 
   http://127.0.0.1:8000/swagger/
   http://127.0.0.1:8000/redoc/

7. Выполнена интеграция с мессенджером Телеграм для рассылки ежедневных напоминаний о привычках зарегистрированным пользователям. Для этого Chat_id нужно внести в профиль пользователя

8. Выполнены настройки CORS

9. Написаны тесты с покрытием > 80%
